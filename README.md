# 🚀 Membuat Website-Menu-Kuliner

# 🍱 Dapur Teien Dining (庭園 ダイニング)

**Teien Dining (庭園 ダイニング)** adalah platform website landing page interaktif untuk restoran kuliner Jepang modern. Website ini dirancang untuk menyajikan suasana khas taman Jepang secara visual, memudahkan pelanggan menjelajahi menu hidangan autentik (seperti Ramen, Sushi, Udon, dan Teh Jepang), serta menyediakan akses cepat untuk informasi reservasi meja dan kontak resto secara online.

# 🛠️ Teknologi yang Digunakan
* HTML
* CSS
* JavaScript

## 📌 Fitur Utama
- **Menu Spesial Interaktif:** Menampilkan daftar kuliner Jepang lengkap dengan deskripsi dan harganya (seperti Udon, Ramen, Sushi, dll).
- **Desain Responsif:** Tampilan website rapi dan nyaman diakses lewat laptop maupun *smartphone*.
- **Informasi Reservasi & Kontak:** Memuat detail lokasi restoran di Google Maps serta tombol pintas ke WhatsApp untuk memudahkan pelanggan memesan meja.
